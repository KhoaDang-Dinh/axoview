# Items, icons and labels

## Adding an item

<!-- keywords: add icon, place, server, database, node, insert, shape library -->

Press **N** or click **Add item** in the tool menu to open the **Elements**
panel. Search for an icon (**Search icons**), then drag it onto the canvas or
click it and click where it should go. **RECENTLY USED** lists the icons you
placed most recently.

## Icon packs

<!-- keywords: aws, gcp, google cloud, azure, kubernetes, k8s, cloud icons -->

The core icon set is always loaded. **AWS Icons**, **Google Cloud Icons**,
**Azure Icons** and **Kubernetes Icons** are extra packs you can turn on or off
in Settings → **Icon Pack Management**. With **Enable Lazy Loading** on, a pack
loads the first time it is needed, which makes startup faster.

## Importing your own icons

<!-- keywords: upload, custom icon, png, svg, own image, logo -->

In the Elements panel, **Import Icons** adds PNG or SVG images as icons. Tick
**Treat as isometric (3D view)** for icons drawn in isometric perspective; untick
it for flat logos and UI elements. **Generate icons with AI** copies a prompt you
can paste into an image generator; replace "my object" with what you need and
import the PNG it makes.

## Name and label

<!-- keywords: difference, caption, title, identity -->

Every item has a **Name** and a **Label** (double-click the item, or
**Details…**, to see both under Metadata).

- The **Name** identifies the item; it is what the Layers panel lists.
- The **Label** is the text drawn on the canvas next to the item.

Renaming in the Layers panel does not change the label on the canvas. **F2** or
**Rename** in the context menu renames the selected item inline.

## Showing, hiding and styling a label

With an item selected, the top bar has **Show label** / **Hide label**, **Label
size**, **Text color** and **Bold / italic / underline / strikethrough**. With
several items selected, size and colour apply to all of them.

## Item details and notes

<!-- keywords: description, metadata, comment, notes -->

Double-click an item (or choose **Details…**) to open its details panel, with
its name, label and **Notes**. **Add/edit note** in the context menu goes
straight to the notes. Notes are saved with the diagram.

## Changing an item's icon

<!-- keywords: swap icon, replace icon, different icon -->

Select one item and use **Change icon** in the top bar. It changes one item at a
time.

## Linking an item

<!-- keywords: hyperlink, url, link to another diagram, drill down -->

Select an item and use **Link** in the top bar: **Link to web** takes a URL,
**Link to diagram** searches your other diagrams. **Open linked diagram** follows
the link.

## Deleting an item

<!-- keywords: remove, delete node, erase -->

Select it and press **Delete** (Backspace on Mac), or choose **Delete** in the
context menu. Connectors attached to it are removed too. **Ctrl+Z** brings it
back.
