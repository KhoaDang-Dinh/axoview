# Settings and shortcuts

## Settings

<!-- keywords: preferences, language, options, configure -->

Open **Settings** from the left dock.

- **Language**: the interface language.
- **Zoom**: **Zoom to Cursor** on or off.
- **Connector Settings**: **Click Mode** or **Drag Mode** for drawing connectors.
- **Icon Pack Management**: turn the AWS, Google Cloud, Azure and Kubernetes
  packs on or off, and **Enable Lazy Loading**.
- **Labels**: **Expand Button Padding**.

**F1** (or **Help** in the zoom controls) opens **Keyboard Shortcuts & Help**
with the full list below.

## Tool keys

<!-- keywords: hotkey, keyboard shortcut, key, tool -->

Tool keys work when you are not typing in a text field.

| Key | Tool |
|---|---|
| S | Select |
| M | Pan |
| N | Add item (Elements panel) |
| R | Rectangle |
| C | Connector |
| T | Text |
| L | Lasso select |
| F | Freehand lasso |
| Esc | Cancel the current tool |

## Editing shortcuts

| Shortcut | Action |
|---|---|
| Ctrl+Z | Undo |
| Ctrl+Y or Ctrl+Shift+Z | Redo |
| Ctrl+X / Ctrl+C / Ctrl+V | Cut / copy / paste |
| Ctrl+A | Select all |
| Delete (Backspace on Mac) | Delete the selection |
| F2 | Rename the selected item, or the diagram |
| Ctrl+] / Ctrl+[ | Bring forward / send backward (add Shift: to front / to back) |
| Ctrl+S / Ctrl+O | Save / open a diagram |
| Q / E | Rotate the view 15° (Shift: quarter turn) |
| F1 | Help |

Use Cmd instead of Ctrl on a Mac.

## Mouse and touch

| Action | Does |
|---|---|
| Click | Select an item; click empty canvas to deselect |
| Double-click | Open the item's details |
| Ctrl/Cmd + click | Add to or remove from the selection |
| Drag on empty canvas | Selection box |
| Right-drag or middle-drag | Pan |
| Right-click (long-press on touch) | Context menu |
| Scroll wheel | Zoom |
| Alt + drag | Orbit the view (Shift snaps to 15°) |
| Alt + click a waypoint | Remove the waypoint |
