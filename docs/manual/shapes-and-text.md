# Rectangles, text boxes and labels

## Drawing a rectangle

<!-- keywords: box, area, zone, group, vpc, subnet, region, boundary, container -->

Press **R** or click **Rectangle** in the tool menu, then drag on the canvas.
Rectangles mark areas such as a VPC, a subnet, a region or a team boundary; they
sit under the items placed on them. **Esc** cancels.

## Styling a rectangle

Select it and use the top bar: **Background color** with **Opacity**, and
**Border** (**Line style**, **Width**, **Border color**). Give it a name in its
details panel; the name is what the Layers panel shows.

## Adding a text box

<!-- keywords: text, paragraph, legend, description, write -->

Press **T** or click **Text** in the tool menu, then click where the text should
go and type. **Esc** cancels. Text boxes hold paragraphs, so use them for
explanations and legends.

## Formatting text in a text box

<!-- keywords: bullet, bulleted list, numbered list, bold, font size, align -->

While editing a text box, the top bar offers **Text size**, **Line spacing**,
**Alignment** (left, centre, right; top, middle, bottom), **Text color**, **Bold
/ italic / underline / strikethrough**, **Bulleted list** and **Numbered list**.
Select text and use **Link selected text** to add a link. **Background color**
and **Border** style the box itself; **Fit to text** in the context menu resizes
it to its content.

## Floating labels

<!-- keywords: title, heading, caption, free text -->

A label is free text placed anywhere on the canvas, for example a title above a
group. Click **Label** in the tool menu and click to place it, or choose **Add
label** in the canvas context menu. Labels can have a background colour and a
link.
